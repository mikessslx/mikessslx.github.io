# mikessslx.github.io

Personal site of Xiang Li, published at <https://mikessslx.github.io>.

Built with Jekyll on the [Minimal](https://github.com/pages-themes/minimal) theme (v0.2.0) through `jekyll-remote-theme`. Page content lives in `_data/` (projects, publications, skills) and `index.html`; the theme overrides are in `_layouts/default.html`, `_includes/` and `assets/css/style.scss`.

## Local preview

```bash
bundle config set --local path vendor/bundle
bundle install
bundle exec jekyll serve
```

Then open <http://127.0.0.1:4000>.
